# EVE Local Alert

纯本地、只读截屏、零内存改动的轻量化 EVE 端游红名预警工具。

玩家选择目标程序窗口，在预览画面中框选任意区域，工具在该区域内按所选颜色识别敌对目标，命中即持续触发本地警报。

## 下载安装

> 运行环境：**Windows 10 / 11（64 位）**。不需要预先安装 Python 或任何运行库。

### 第一步：下载

点这里打开下载页 → **[📥 下载最新版](https://github.com/ruanpy-1104/eve-local-alert/releases/latest)**

页面下方 **Assets（附件）** 里有两个文件，**任选一个下载即可，不用都下**：

| 文件名 | 推荐 | 怎么用 | 区别 |
| --- | --- | --- | --- |
| **`eve-alert-v1.2.0.exe`**<br>（约 98 MB） | ⭐ **不确定就选这个** | 下载后**双击直接运行**，不用安装、不用解压 | 全部内容压在一个 exe 里。每次启动要先自解压到临时目录，**启动慢几秒** |
| `eve-alert-v1.2.0-portable.zip`<br>（约 102 MB） | 想启动更快时选 | **先解压**整个压缩包到任意文件夹，再双击里面的 `eve-alert.exe` | 解压后是 `eve-alert.exe` + `_internal` 文件夹，**启动快**。注意：`eve-alert.exe` 必须和 `_internal` 放在一起，单独拷出来会打不开 |

文件名里的 `v1.2.0` 是版本号，会随新版本变化，认准 `.exe` 和 `-portable.zip` 后缀即可。两个包功能完全一样，**只有启动速度和存放方式的区别**。

### 第二步：运行

双击后如果 Windows 弹出蓝色的「**Windows 已保护你的电脑**」提示：点「**更多信息**」→「**仍要运行**」。

这是因为本项目没有购买微软代码签名证书（一年数千元），所有新发布的小众软件都会有这个提示，不代表有病毒。个别杀毒软件可能对单文件 exe 误报，若被拦截可改用 portable.zip 版，或在杀软里添加信任。

### 关于卸载与个人数据

绿色软件，不写注册表：

- 配置和日志存在 `%APPDATA%\eve-alert`（地址栏粘贴这个路径可直达），**不会**在程序旁边生成文件
- 卸载：直接删掉 exe（或解压出来的文件夹）即可；想彻底清干净，把上面那个 `eve-alert` 文件夹也删掉
- 升级：下载新版覆盖旧文件即可，你的框选区域、颜色等设置会保留

## 特性

- **按窗口内容捕获**：PrintWindow 直接渲染所选窗口自身画面，即使被其他应用遮挡也只监控该窗口，不影响其他程序操作
- **预览画面内框选监控区域**：归一化坐标存储，跨分辨率稳定；无需在被监控程序界面上操作；最小支持 2×2 像素选区（单击不触发框选），框选时不显示分辨率
- **4 种 EVE 总览颜色**：红 / 橙 / 黄 / 灰白（取自游戏总览调色板），色块勾选多选警报颜色；四个色相的识别窗口互不重叠（勾「橙」不会连带命中「黄」）
- **识别程度调节**：固定档位 0 / 50 / 100（左宽右严），调节饱和度 / 明度门槛——越严格越排除灰暗杂色，误报时往严格调、漏报时往宽松调；首次使用默认 50（适中），之后记住上次选择
- **连续警报**：识别到目标即持续播放警报音，直到目标消失（无冷却）；停止时当前周期自然放完，不截断爆音
- **预警暂停**：听到警报后可手动暂停播报，命中不再报警（顶部状态栏实时显示黄色「已暂停」）；暂停至少持续设定时长（默认 10 秒，可在「暂停设置」调整，0 秒为不延时），时长满后目标**不在视野**才自动恢复，下次命中继续报警——进出空间站等短暂黑屏不会提前解除暂停
- **最小化提醒**：监控中目标窗口最小化时播放提示音并置顶面板提醒玩家（仅提示最小化，目标关闭时提示重新选择）
- **远程预警（可选）**：开启后，警报触发时通过 [Server酱](https://sct.ftqq.com/r/3353) 向你的微信推送一条提醒，人不在电脑前也能收到通知；首次使用有注册引导与测试通知；每轮警报只发一条，再次提醒需同时满足「距上次**推送** ≥ 5 秒」与「敌方已消失」，另可选更长的冷却间隔（默认 5 分钟，免费用户建议开启，把每日 5 条免费额度留给真正需要的警报，与内置冷却互不影响）；发送失败只记日志，不影响本地警报音；**每次启动默认关闭**（SendKey 与冷却等设置保留，勾选后本次会话生效）。开启后「远程预警」按钮会换成与「开始预警」相同的**主色样式**作为状态提示，关闭后即恢复原样
- **独立预览窗口**：「预览」按钮单独显示框选区域画面与识别信息，不占用主面板
- **无人机监控（可选，字样与血条双确认）**：独立框选无人机列表区域，不碰敌对 ROI。识别同时匹配「空闲」「战斗中」「返回中」的具体字样模板，并要求同一行右侧存在血条；只有字样匹配且血条绑定成功才计为有效无人机行。只要存在有效空闲行且没有战斗 / 返回中，持续到用户设定延时（默认 30 秒，范围 1–120 秒）即播放一次「叮咚」，不要求之前发生过战斗。暂停预警期间「叮咚」静音，恢复后不补响。只有「战斗中 + 红血条」连续 2 帧才循环急促报警，状态不再是战斗中立即停止。预警运行中可打开无人机设置，应用后新配置立即生效，不需要停止或重启敌对预警
- **飞行状态悬浮窗**：置顶显示安全 / 敌袭 / 暂停 / 最小化 / 目标关闭等纯状态；启用无人机监控时增加第二行状态，仅在空闲提示实际播放后显示「无人机：空闲」（绿色），仅在受损急促报警实际触发时显示「无人机：受损」（红色）。可拖动、记住位置，锁定后鼠标穿透，仅从主面板菜单解锁
- **未监控状态保护**：停止监控、窗口丢失、最小化或出错后清理无人机悬浮状态；面板只接受当前监控线程的无人机信号，避免旧线程收尾信号的残留急促报警
- **流程自动化**：选择目标后自动进入框选；停止预警后自动回到框选；未选择目标时点「开始预警」等价于「选择程序」（选完进入框选，再点一次才开始监控，避免来不及框选）
- **低占用**：默认 6 FPS 低帧率 + 下采样检测，CPU 占用低
- **默认完全本地**：无任何数据上传；远程预警默认关闭，开启后仅在警报触发时向 Server酱 发送一条警报文字通知（不含画面 / 数据）
- **只读截屏**：不修改内存、不注入、不 Hook

## 从源码运行（开发者）

环境：Windows 10 / 11（x64）+ Python 3.11 及以上。

### 方式一：uv（推荐）

[**uv**](https://docs.astral.sh/uv/) 比 venv + pip 快得多，自动创建虚拟环境，并按 `uv.lock` 锁定依赖版本，各机器环境一致。

```powershell
# 1. 安装 uv（任选其一，只需一次）
winget install astral-sh.uv
# 或：powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# 2. 克隆并进入项目
git clone https://github.com/ruanpy-1104/eve-local-alert.git
cd eve-local-alert

# 3. 安装依赖（自动创建 .venv 并按 uv.lock 锁定版本）
uv sync

# 4. 首次运行：复制配置模板（可选，缺失时程序自动使用默认值）
Copy-Item config.example.json config.json

# 5. 运行
uv run python main.py
```

> 之后每次只改动了依赖（升级 / 新增）再跑一次 `uv sync` 即可；`uv run` 会直接使用项目内的 `.venv`，无需手动激活。

常用命令：

| 命令 | 作用 |
| --- | --- |
| `uv sync` | 按 `uv.lock` 安装 / 同步依赖（含 pytest 等 dev 依赖） |
| `uv sync --no-dev` | 只装运行依赖，不装 pytest |
| `uv sync --extra dxgi` | 额外安装可选的 `dxcam`（独占全屏下的 DXGI 捕获） |
| `uv run python main.py` | 在项目环境里运行，无需手动激活 venv |
| `uv add <包名>` | 新增依赖，自动写入 `pyproject.toml` 并更新 `uv.lock` |
| `uv lock --upgrade` | 升级锁定的依赖版本 |

### 方式二：venv + pip

不想装 uv 也可以，依赖清单 `requirements.txt` / `requirements-dev.txt` 保留可用：

```powershell
git clone https://github.com/ruanpy-1104/eve-local-alert.git
cd eve-local-alert

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 首次运行：复制配置模板（可选，缺失时程序自动使用默认值）
Copy-Item config.example.json config.json

python main.py
```

> 两份依赖清单与 `pyproject.toml` 内容一致，改依赖时请同步更新，避免两条路径装出不同版本。

## 使用流程

1. **选择程序**：启动后弹出「选择程序」，选中要监控的窗口（也可在面板点「选择程序」更换）
2. **自动框选**：选择完成后自动进入框选模式，在面板预览画面中**拖动鼠标**框选监控区域（框选时不显示分辨率）
3. **颜色选择**：点击「颜色选择」，勾选需要警报的 EVE 总览颜色（红 / 橙 / 黄 / 灰白，默认全选；至少需勾选一种），识别程度固定档位 0/50/100 调节松紧，点「应用」
4. **预览**：点击「预览」可打开独立窗口（需先选择目标程序，未选择时按钮置灰），查看框选区域画面与识别信息
5. **开始预警**：框选完成后点「开始预警」开始监控；未选择目标程序时点「开始预警」等价于「选择程序」——选择窗口后自动进入框选，**需再点一次「开始预警」**才真正开始。目标窗口被识别到所选颜色即持续警报，直到目标消失；听到警报后可点「暂停预警」静音（命中不报警，暂停至少持续设定时长后目标不在视野即自动恢复，时长可在「暂停设置」调整）；停止预警后自动回到框选模式
6. **无人机监控（可选）**：点击「无人机」，在独立窗口中框选无人机列表，勾选「启用无人机监控」并设置「空闲提示延时」（默认 30 秒，范围 1–120 秒）后点「应用」。即使预警正在运行也可打开设置，敌对监控不会停止；应用后的启用状态、延时和 ROI 会在下一帧自动生效。未选择目标程序时会先进入选择程序流程。识别会逐行同时确认「空闲」/「战斗中」/「返回中」字样与右侧同排血条，缺少字样或不匹配、缺少血条的行都不会计入。只要存在有效空闲行且没有战斗或返回中，持续到设定延时即提示一次「叮咚」；无需等待之前发生过战斗。中途出现非空闲、战斗或返回中会重新计时，暂停预警期间该提示静音且不显示空闲状态。被攻击急促报警只响应「战斗中 + 红血条」，脱离战斗状态立即停止；停止监控后旧线程的收尾信号不会重新启动急促报警
7. **悬浮窗**：点击「悬浮窗」菜单可显示 / 隐藏、锁定鼠标穿透或重置到主屏右上角。启用无人机监控时，主状态下方仅在“叮咚”实际播放后显示「无人机：空闲」（绿色，普通字号），仅在受损急促报警实际触发时显示「无人机：受损」（红色，加粗）；未触发、未启用或未监控时该行隐藏。拖动结束后位置自动保存，锁定状态只能从主面板菜单解除
8. **远程预警（可选）**：点击「远程预警」→「启用远程预警」，首次使用按引导打开 Server酱 注册页（微信扫码登录），复制 SendKey 粘贴保存；可点「发送测试通知」验证微信能收到。免费用户建议勾选「启用冷却间隔（免费用户请勾选）」，默认 5 分钟，避免短时间内重复推送消耗每日 5 条免费额度。此后警报触发时微信会收到一条提醒
