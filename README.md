# EVE Local Alert

纯本地、只读截屏、零内存改动的轻量化 EVE 端游红名预警工具。

玩家选择目标程序窗口，在预览画面中框选任意区域，工具在该区域内按所选颜色识别敌对目标，命中即持续触发本地警报。

## 特性

- **按窗口内容捕获**：PrintWindow 直接渲染所选窗口自身画面，即使被其他应用遮挡也只监控该窗口，不影响其他程序操作
- **预览画面内框选监控区域**：归一化坐标存储，跨分辨率稳定；无需在被监控程序界面上操作；最小支持 2×2 像素选区（单击不触发框选），框选时不显示分辨率
- **12 种 EVE 总览颜色**：红 / 橙红 / 橙 / 灰白 / 绿 / 青绿 / 深青 / 蓝 / 天蓝 / 紫 / 品红 / 黑，色块勾选多选警报颜色
- **识别程度调节**：固定档位 0 / 50 / 100（左宽右严，原 75 归并到 50、50 归并到 0），误报时往严格调，漏报时往宽松调
- **连续警报**：识别到目标即持续播放警报音，直到目标消失（无冷却）；停止时当前周期自然放完，不截断爆音
- **预警暂停**：听到警报后可手动暂停播报，命中不再报警；目标**持续未出现**达设定延时（默认 10 秒，可在「暂停设置」调整，0 秒为不延时）后自动恢复，下次命中继续报警——进出空间站等短暂黑屏不会误解除暂停
- **最小化提醒**：监控中目标窗口最小化时播放提示音并置顶面板提醒玩家（仅提示最小化，目标关闭时提示重新选择）
- **远程预警（可选）**：开启后，警报触发时通过 [Server酱](https://sct.ftqq.com/r/3353) 向你的微信推送一条提醒，人不在电脑前也能收到通知；首次使用有注册引导与测试通知；每轮警报只发一条，再次提醒需同时满足「距上次**推送** ≥ 5 秒」与「敌方已消失」，另可选更长的冷却间隔（默认 5 分钟，免费用户建议开启，把每日 5 条免费额度留给真正需要的警报，与内置冷却互不影响）；发送失败只记日志，不影响本地警报音；**每次启动默认关闭**（SendKey 与冷却等设置保留，勾选后本次会话生效）
- **独立预览窗口**：「预览」按钮单独显示框选区域画面与识别信息，不占用主面板
- **流程自动化**：选择目标后自动进入框选；停止预警后自动回到框选
- **低占用**：默认 6 FPS 低帧率 + 下采样检测，CPU 占用低
- **默认完全本地**：无任何数据上传；远程预警默认关闭，开启后仅在警报触发时向 Server酱 发送一条警报文字通知（不含画面 / 数据）
- **只读截屏**：不修改内存、不注入、不 Hook

## 快速开始

```powershell
cd "d:\Code\EVE Alert"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 首次运行：复制配置模板（可选，缺失时程序自动使用默认值）
Copy-Item config.example.json config.json

python main.py
```

## 使用流程

1. **选择程序**：启动后弹出「选择程序」，选中要监控的窗口（也可在面板点「选择程序」更换）
2. **自动框选**：选择完成后自动进入框选模式，在面板预览画面中**拖动鼠标**框选监控区域（框选时不显示分辨率）
3. **颜色选择**：点击「颜色选择」，勾选需要警报的 EVE 总览颜色（默认红 / 橙红 / 橙 / 灰白），识别程度固定档位 0/50/100 调节松紧，点「应用并保存」
4. **预览**：点击「预览」可打开独立窗口（需先选择目标程序，未选择时按钮置灰），查看框选区域画面与识别信息
5. **开始预警**：目标窗口被识别到所选颜色即持续警报，直到目标消失；听到警报后可点「暂停预警」静音（命中不报警，目标持续离开设定延时后自动恢复，延时可在「暂停设置」调整）；停止预警后自动回到框选模式
6. **远程预警（可选）**：点击「远程预警」→「启用远程预警」，首次使用按引导打开 Server酱 注册页（微信扫码登录），复制 SendKey 粘贴保存；可点「发送测试通知」验证微信能收到。免费用户建议勾选「启用冷却间隔（免费用户请勾选）」，默认 5 分钟，避免短时间内重复推送消耗每日 5 条免费额度。此后警报触发时微信会收到一条提醒

本工具仅做只读屏幕捕获，不读取或修改游戏进程内存、不注入、不挂 Hook、默认不联网（远程预警为可选功能，开启后仅在警报触发时向 Server酱 发送一条文字通知）。任何第三方工具的使用最终以 CCP 用户协议（EULA / TOS）为准，请在使用前自行确认相关政策。
