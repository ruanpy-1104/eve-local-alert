# EVE Local Alert v1.2.0

纯本地、只读截屏的 EVE 端游预警工具。本次更新加入**无人机监控**与**置顶飞行状态悬浮窗**，并对识别与告警时序做了多处实机校准。

## 新增

### 无人机监控（可选，默认关闭）

- 独立的「无人机」设置窗口与独立框选区域（`drone.roi`），不影响敌对监控的框选
- 识别不再只按颜色：每一行必须同时满足 **「空闲 / 战斗中 / 返回中」具体字样模板匹配** 与 **右侧同排血条**，才计为有效无人机行
- 全部无人机空闲（没有任何「战斗中」或「返回中」）持续到设定时间后，播放一次「叮咚」并在悬浮窗显示「无人机：空闲」
- 空闲提示延时可在设置窗口调整：**1–120 秒，默认 30 秒**
- 无人机被攻击（战斗中 + 血条变红，连续 2 帧）时循环播放急促报警；状态脱离战斗立即停止
- 无人机声音使用独立 `QSoundEffect`，可与敌袭的 `winsound` 警报同时播放
- 预警运行中也可以打开设置窗口；应用后新的启用状态 / 延时 / ROI 在下一帧生效，**不会停止敌对预警**

### 飞行状态悬浮窗

- 无边框置顶小窗：安全飞行中（绿）/ 敌袭（红）/ 已暂停（黄）/ 目标最小化 / 目标关闭 / 监控中 / 待机中
- 无人机状态作为第二行：`无人机：空闲`（绿）、`无人机：受损`（红加粗），**只在对应提示 / 报警实际触发时显示**
- 可拖动、记住位置；「锁定位置」后鼠标穿透，只能从主面板菜单解锁；支持重置到主屏右上角

## 变更

- 取消无人机数量设置：不再比较配置数量，改为「没有战斗中 / 返回中，且至少有一行有效空闲」即进入空闲判定
- 取消「必须先发生过战斗」的限制：空闲持续到设定时间即可提示
- 预警暂停期间「叮咚」静音；被暂停吞掉的提示不会补响，也不会显示空闲悬浮状态
- 监控线程每帧只做一次 PrintWindow，从同一帧裁剪敌对 ROI 与无人机 ROI

## 修复

- 停止预警后旧线程收尾信号可能重新触发急促报警
- 小尺度下「战斗中」文字笔画被误判为血条，导致误报无人机受损
- `QSoundEffect` 首次播放时音频尚未加载完成导致无声
- 悬浮窗随主面板最小化被隐藏、监控中显示悬浮窗状态不刷新
- 半残坐标恢复、预览窗与无人机设置窗并行抓屏等边界问题

## 使用提示

- 无人机 ROI 必须同时框到每行的**状态字样**（空闲 / 战斗中 / 返回中）和**右侧血条**，否则该行不会被计入
- 窗口缩放后模板匹配支持约 0.5–1.5 倍；如果游戏 UI 缩放变化很大或识别异常，重新框选一次即可
- 工具仍为只读截屏：不读内存、不注入、不 Hook；远程预警默认关闭

## 已知限制

- 独占全屏下 PrintWindow 可能取不到画面，会回退到屏幕抓取；建议窗口化或无边框全屏
- ROI 之外的目标无法识别
- 游戏更新若调整 UI 配色或字体，可能需要重新提取模板 / 重新框选
