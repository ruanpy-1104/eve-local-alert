# EVE Local Alert v1.2.1

本次更新集中在**总览误报/白图标漏报**与**远程预警入口**，不改变捕获方式、警报音与无人机功能。

## 重点

### 1. 总览检测器重写：方格 + 网格 + 四角颜色

- 检测单位从「颜色块」改为「玩家名字前的阵营方格」；
- 不依赖名字：ROI 只框图标列即可；
- 不依赖中心图形：白星、单条/两条横杠、十字、圆点、六边形、空白都不影响；
- 只采样外环与四角颜色，避开中心 50%；
- 固定 x 列 + 行距 + 相位网格，至少 2 行才锁定；网格外的行星、红灯、背景块丢弃；
- 无网格时只有恰好 1 个高置信方格走单方形模式，否则 fail-safe 不报警；
- 空槽（自己的行/空行）不补假目标；
- 检测始终 1×，`downscale` 兼容旧配置但已忽略。

### 2. 修复两张实测误报

- `样例/空间站红灯列表.png`
- `样例/太空中列表.png`

旧版本会因半透明背景下出现相近颜色块而报警；新版本要求方格轮廓 + 网格位置，两个样例连续 3 帧均为 `False`。

### 3. 修复白图标漏报

- 白色图标面可能比亮背景更暗（V185 对 V205），不再要求「白色=最亮」；
- 低对比白格用「局部暗面/自适应阈值 + 中心高对比图案 + 方格边阶跃」补齐；
- 中心图案支持白星、单条/两条横杠、十字等；
- 单行低对比白图标也可识别；
- 空槽里的背景亮星不会被补成白方块。

### 4. 识别程度改为兼容模式

- UI 移除 0/50/100 滑块，改为下拉框：
  - 自动（默认）
  - 低对比兼容（HDR / 亮背景白图标漏报 / A/N 饱和度差异）
  - 严格（误报较多时）
- 兼容模式只调整对比度、边缘、颜色阈值；方格/网格/中心图案判定不变。
- 旧 `detection.strictness` 自动迁移：
  - ≤25 → `low_contrast`
  - 50 → `auto`
  - ≥75 → `strict`
- 保存后只写 `detection.compat`，旧配置无需手动修改。

### 5. 远程预警增加「获取 SendKey」

- 远程预警对话框中，「获取 SendKey」按钮与 SendKey 输入框同一行，**始终可见**；
- 点击打开 Server酱 注册页：https://sct.ftqq.com/r/25928
- 首次引导文案同步指向该按钮。

## 升级说明

- 直接覆盖旧文件即可；ROI、颜色、无人机、悬浮窗设置保留。
- 旧 `detection.strictness` 会在加载时迁移为 `detection.compat`；下次保存后旧键消失。
- 若升级后白图标漏报：颜色选择 → 兼容模式 → 「低对比兼容」。
- 若误报较多：先确认 ROI 只框图标列，再试「严格」。

## 已知限制

- 单行列表没有足够数据拟合行距，只能依赖单方形模式，可靠性低于多行网格；
- 极端情况下背景对象恰好形成同尺寸方格并精确落在同一列/行距/相位，仍有残余误报风险；
- 游戏 UI 改版或大幅更换缩放后建议重新框选；
- HDR / A/N 色彩差异由兼容模式吸收，但仍建议实机确认白/红/橙/黄四类图标。
